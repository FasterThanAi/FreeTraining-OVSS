names different content: a flooded building, a photovoltaic array and forest

what you intend to map is the use case; revising words until one picture looks
better is not, and only `_b` involved any revision at all.

⛔ No further revisions. If a class is missing from a scene, report that the
model assigns the nearest available word — that is the honest cost of an open
class list and it is what the figure caption says.
